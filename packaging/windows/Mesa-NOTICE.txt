Mesa software OpenGL in the TMOP server package
================================================

opengl32.dll and libgallium_wgl.dll in this package are Mesa @MESA_VERSION@ (https://mesa3d.org),
as built by the mesa-dist-win project (MinGW-w64 x64 release package):
https://github.com/pal1000/mesa-dist-win/releases/tag/@MESA_VERSION@

They give TMOP OpenGL on machines without a graphics driver. TMOP draws with llvmpipe, Mesa's
software renderer, which runs on the CPU. Delete both files to use the graphics driver instead.
